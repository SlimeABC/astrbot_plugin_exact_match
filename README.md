# 精确匹配

AstrBot 精确匹配自动回复插件：消息内容与触发词完全一致时才回复，避免子串误触。

## 功能

- **完全匹配**：配置 `test` 后，只有 `test` 会触发，`Test`、`test123` 不会
- **按组配置**：每条规则由“触发词 + 回复”组成，可配置多组、互不影响
- **群聊触发可配置**：每条规则可单独设置是否需要先触发机器人；默认需要 @机器人（或唤醒词），关闭后该规则在群聊中直接发送也会回复，私聊始终直接匹配
- **直接回复**：不调用模型，响应稳定、无额外费用

## 安装

1. 将插件目录放到 `AstrBot/data/plugins/`
2. WebUI → 插件 → 重载插件
3. 打开插件配置，在“精确匹配规则”中添加组

## 配置

“精确匹配规则”是一组可增删的配置，每组包含：

| 字段 | 说明 |
| --- | --- |
| 触发词 | 需要完全匹配的消息内容，不含唤醒词；首尾空格会被忽略，区分大小写 |
| 指定机器人（Bot ID） | 填写平台设置里的 Bot ID，也可填写机器人账号 ID；留空表示对所有机器人生效 |
| 需要触发机器人 | 默认开启。开启后这条规则在群聊中需要 @机器人 或使用唤醒词；关闭后群聊直接发送触发词也会回复，私聊不受影响 |
| 回复内容 | 匹配成功后直接发送的文本，支持换行 |

默认规则：

- `test` → `pass`

同一触发词配置多次时，按顺序使用第一条满足 Bot ID 和触发方式条件的规则。

> 1.0.1 起配置改为按组维护。从 1.0.0 升级后，旧的“触发词列表 / 回复列表”配置不再使用，请在 WebUI 中重新添加规则。

## 使用示例

配置：

- `test` → `pass`
- `help` → `help document` 换行 `v1.0` 换行 `this is a bot`

对话（以下为私聊示例；群聊中需先 @机器人 或使用唤醒词）：

```text
用户：test
机器人：pass

用户：help
机器人：help document
       v1.0
       this is a bot

用户：Test
机器人：调用 LLM 或无响应

用户：help me!!!
机器人：调用 LLM 或无响应
```

## 说明

- 匹配区分大小写，`Test` 不会触发 `test`
- 私聊始终直接发送匹配；每条规则可单独设置“需要触发机器人”，默认群聊中需要 @机器人（或唤醒词）
- 规则填写了“指定机器人（Bot ID）”时，只有对应机器人收到匹配消息才会回复；留空则对所有机器人生效
- 匹配对象是去掉唤醒词和 @机器人 之后的文本
- 空触发词或空回复的规则会被跳过，不会生效
